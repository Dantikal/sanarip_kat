# Санарип кат — документооборот

## Backend (Django)
```bash
cd backend
pip install -r requirements.txt
python3 manage.py migrate          # создаёт таблицы, виды документов и тестовых пользователей
python3 manage.py runserver        # http://127.0.0.1:8000/api/
python3 manage.py test documents   # тесты сценария регистрации и подписи
```

## Frontend (React + Vite)
```bash
cd frontend
npm install
npm run dev                        # http://localhost:5173
```
Запросы `/api` проксируются на Django (порт 8000), поэтому сначала запустите backend.

## Сценарий
Подписывают только **администраторы** (галочка «Администратор (может подписывать)» в профиле
пользователя в админке Django: `/admin/` → Profiles). Раздел «На подпись» есть только у них.

1. Любой пользователь: «Зарегистрировать» → вид документа → форма. Подписывающий (шаг 1) выбирается
   только из администраторов, остальные согласующие — по желанию. Документ попадает к УДО
   в «Ждет регистрацию» (без номера). Документы, созданные самим УДО, регистрируются сразу.
2. УДО: «Ждет регистрацию» → документ →
   - «Зарегистрировать» — присваивается номер, документ остаётся в «Ждет регистрацию» до оформления резолюции;
   - «На доработку» с комментарием — документ уходит в «На доработке»; у автора появляется такой же раздел,
     он может заменить официальный файл и «Отправить на регистрацию повторно»;
   - «Отказать» с причиной — документ уходит в «Отказанные», автор видит причину.
3. УДО (там же, в «Ждет регистрацию»): зарегистрированный документ → справа резолюция: исполнители (первый — сводящий), тип, срок,
   текст → «Отправить на подпись» (уходит выбранному при регистрации администратору).
4. Администратор: «На подпись» → документ → «Подписать».
5. Исполнители: документ появляется в «Вы сводящий»; открытие документа = «ознакомлен».
6. УДО: подписанный документ попадает в «Ждет закрытия» → «Закрыть документ».
7. УДО: закрытый документ попадает в «Готово к архивированию» → «Отправить в архив» (виден в меню «Архив»).

Разделы УДО в «Ожидается Ваше действие»: Ознакомиться, Ждет регистрацию, Ждет закрытия, Отказанные,
На доработке, Готово к архивированию.
